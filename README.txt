SYED & SONS — ANIMATED FASHION WEBSITE
======================================

WHAT'S INCLUDED
- Responsive editorial fashion landing page
- Floating glossy bubble / orb effects
- Blur-to-clear heading entrance animations
- Scroll reveal animations
- Hover movement on product visuals
- Muted looping video slots (autoplay when a video file is present)
- GitHub Pages compatible static HTML/CSS/JavaScript

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.
3. For the best video behavior, use a local server or GitHub Pages.

HOW TO ADD YOUR VIDEOS
This package does not include the reference site's copyrighted video or footage.
Add your own licensed MP4 files to the assets folder:
- assets/hero.mp4  (main full-screen background video)
- assets/detail.mp4 (secondary campaign video)

Use landscape 16:9 or portrait footage, encoded as H.264 MP4.
Videos are set to autoplay, muted, loop and playsinline. Browsers usually block
autoplay with sound, so keep muted for automatic playback.

PUBLISH ON GITHUB PAGES
1. Go to your GitHub repository.
2. Upload index.html, style.css, script.js, README.txt and the assets folder.
3. Commit changes to the branch/folder configured in Settings > Pages.
4. Open your GitHub Pages URL after the deployment completes.

IMPORTANT
- This is an original AVANT-GARDE fashion-inspired design, not a pixel-perfect
  copy of the reference site.
- Actual campaign video is not included. You need to provide licensed footage
  to make the video slots play real video. The rest of the motion effects work
  without video files.
